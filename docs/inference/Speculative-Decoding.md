# 第 5 章 Speculative Decoding

普通方式是大模型一个个生成这些字,投机方式是小模型先猜一批,大模型每轮验证一批,对的就直接保留,错的当场纠正

## 1. 什么是DFlash

小模型怎么能够猜一批？

它先一个个出，攒成一批，再一起交给大模型验，省在“小模型跑几步便宜”。

举例：我喜欢 吃 苹果

用同一段已知上下文, 加上“这里是第4”和“这里是第5”这样的位置信息,分别同时去猜两个位置的词。它不是先生成第4个,再把它喂回去生成第5个,而是两个都直接看“我喜欢”加位置编码,各自输出一个预测

省在哪里？

并行草稿是“先把几个候选词都写出来”,大模型就能把这些位置一起算一遍,不用排队等上一个结果,算完再决定哪些候选通过、哪些丢掉。省下的是多轮等待和重复启动的时间。一次验证多走几步,少跑几轮,只要这一轮猜对够多,就能把前面多花的草稿成本赚回来,整体就更快。

## 2. 什么是Eagle3

EAGLE-3 则是小模型借助大模型的中间特征,一个词一个词地猜,攒出一批再交给大模型。

## 3. 什么是DSpark

DSpark 结合两种思路,用并行打底,再加一点逐步计算加强前后依赖,但不是单纯逐个猜,也不完全像 DFlash 那样一次性并行猜完。
